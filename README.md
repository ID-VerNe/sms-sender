# SmsSender 短信转邮件转发器

这是一个为 Android（特别是魅族 Flyme 系统）设计的自动化工具，可以将收到的短信自动通过 SMTP 转发到指定的电子邮箱。

## 功能
- 监听实时短信。
- 支持 SMTP (SSL) 协议发送邮件。
- 详细的日志记录 (Logcat 过滤 `SmsSender_Trace`)。
- 前台服务保持，防止系统杀掉进程。
- 开机自启动支持。

## 使用说明
1. **配置 SMTP**：在 App 中输入发件邮箱服务器、账号和授权码。
2. **配置接收邮箱**：输入您希望接收通知的邮箱。
3. **开启服务**：点击开关开启转发服务。
4. **测试**：点击“发送测试邮件”验证配置是否正确。

## 关键：解决验证码无法读取
如果您发现普通短信可以转发，但验证码短信无法转发，请检查以下设置：
1. **系统短信拦截**：在魅族手机的“手机管家” -> “骚扰拦截”中，检查是否拦截了验证码短信，或者是否限制了第三方应用读取验证码。
2. **通知类短信权限**：在“权限管理”中，确保本应用拥有“读取通知类短信”的权限。
3. **验证码安全保护**：部分系统有“验证码安全保护”功能，会阻止第三方 App 读取验证码。请在系统设置 -> 安全 -> 验证码安全保护中尝试关闭。

## 针对魅族 (Flyme) 的保活设置
为了确保应用不被系统杀掉，请务必手动完成以下设置：
1. **后台管理**：手机管家 -> 权限管理 -> 后台管理 -> 找到 "SmsSender" -> 设置为 **“允许后台运行”**。
2. **自启动**：手机管家 -> 权限管理 -> 自启动管理 -> 开启 "SmsSender"。
3. **电池优化**：设置 -> 电池 -> 电池优化 -> 不优化 "SmsSender"。
4. **锁屏清理**：确保应用不被锁屏清理列表包含。

## 日志调试
使用 Android Studio 或 ADB 查看日志：
```bash
adb logcat -s SmsSender_Trace SmsReceiver MailSender
```

## 技术细节
- **库**：使用了 `com.sun.mail:jakarta.mail` 处理邮件。
- **线程**：使用 Kotlin Coroutines 进行异步网络操作。
- **服务**：使用 `Foreground Service` (前台服务) 配合持久化通知。
