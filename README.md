# SmsSender

> 一个 Android 短信自动转发工具。通过通知栏监听捕获短信，经 SMTP 转发到指定邮箱。支持验证码 (OTP) 自动提取、快递取件码识别、关键词转发规则。

## 功能

| 功能 | 说明 |
|------|------|
| 短信自动转发 | 监听系统通知栏短信，自动转发到指定邮箱 |
| 验证码提取 | 启发式正则提取，覆盖 20+ 语言，0 网络依赖，毫秒级响应 |
| 快递取件码识别 | 支持 30+ 快递公司/驿站，自动识别取件码和公司名称 |
| 关键词转发规则 | 自定义关键词匹配，不同短信转发到不同邮箱 |
| 邮件主题优化 | 转发时自动用验证码/取件码作为邮件主题，一目了然 |
| 前台服务保活 | 持久化通知防止系统回收进程 |
| 开机自启动 | 设备重启后自动恢复转发服务 |
| LLM 降级提取 | 可选 LLM API 作为验证码提取的兜底方案 |

## 使用说明

### 1. 配置 SMTP

在 App 设置页输入发件邮箱服务器信息：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| SMTP 服务器 | 发件邮箱的 SMTP 地址 | `smtp.qq.com` |
| 端口 | SMTP 端口（465=SSL, 587=STARTTLS） | `465` |
| 发件邮箱 | 完整邮箱地址 | — |
| 授权码 | SMTP 授权码（非登录密码） | — |

### 2. 配置接收邮箱

输入您希望接收短信通知的邮箱地址。

### 3. 开启服务

点击开关开启转发服务。App 会显示前台通知 `SmsSender 运行中`。

### 4. 验证配置

点击"发送测试邮件"按钮验证配置是否正确。

## 验证码提取

App 内置了基于启发式正则的验证码提取引擎，取自 [jd1378/otphelper](https://github.com/jd1378/otphelper) (Apache-2.0)：

- **覆盖范围**：中文、英文、日文、韩文、俄语等 20+ 语言的验证码格式
- **性能**：0-2ms，无网络请求，无需 API Key
- **隐私**：所有提取在本地完成，短信内容不离开设备

**提取优先级**：验证码 → 快递取件码 → LLM 兜底（可选）

## 快递取件码识别

App 支持从快递短信中提取取件码和识别快递公司，取自 [yimeifun/ExpressPickupHelper](https://github.com/yimeifun/ExpressPickupHelper) (MIT)：

- **支持驿站**：菜鸟驿站、妈妈驿站、丰巢、兔喜生活、快宝驿站、驿收发、熊猫快收、心甜智能柜等 23+ 驿站
- **支持快递公司**：顺丰、中通、圆通、韵达、申通、极兔、邮政、京东等 16+ 快递公司
- **格式覆盖**：40+ 正则模式，涵盖"请凭取件码"、"取件码为"、"码:xxx"等常见格式

## 转发规则

支持自定义关键词转发规则：

1. 在"规则"页添加规则，设置匹配关键词和目标邮箱
2. 当收到的短信正文包含关键词时，会自动转发到该规则指定的邮箱
3. 支持多条规则，每条可独立启用/禁用
4. 默认接收邮箱始终参与转发，与规则互不冲突

## 针对魅族 (Flyme) 的保活设置

| 设置项 | 操作路径 |
|--------|----------|
| 后台运行 | 手机管家 -> 权限管理 -> 后台管理 -> SmsSender -> **允许后台运行** |
| 自启动 | 手机管家 -> 权限管理 -> 自启动管理 -> 开启 SmsSender |
| 电池优化 | 设置 -> 电池 -> 电池优化 -> **不优化** SmsSender |
| 锁屏清理 | 确保 SmsSender 不在锁屏清理列表 |

## 验证码无法读取的排查

如果普通短信可以转发但验证码短信无法转发：

1. **系统短信拦截**：手机管家 -> 骚扰拦截 -> 检查是否拦截了验证码短信
2. **通知类短信权限**：权限管理 -> 确保本应用有"读取通知类短信"权限
3. **验证码安全保护**：设置 -> 安全 -> 验证码安全保护 -> 尝试关闭
